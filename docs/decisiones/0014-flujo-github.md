# 0014 · Flujo en GitHub: issues, ramas, PRs y sin coautoría de IA

**Estado:** aceptada · 2026-10

## Contexto

Se quiere trazabilidad total: entender qué se hizo, cuándo y por qué.

## Decisión

Una **issue** por cambio, rama `tipo/numero-descripcion`, commits Conventional Commits en español con `Refs #N`, y un **PR que explica cada commit**, unido con **merge commit**. Etiquetas por tipo, área y prioridad, y milestone MVP. **No se agrega coautoría ni firmas de herramientas de IA** en commits, PRs ni issues.

## Descartado

Squash merge (pierde el detalle de los commits).

## Consecuencias

La integración de GitHub de Claude agrega automáticamente la línea "Generated by Claude Code" al final de issues, PRs y comentarios, y no se puede desactivar desde la sesión. El equipo la quita después editando el texto (por ejemplo con `gh issue edit` / `gh pr edit`).
